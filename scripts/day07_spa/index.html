Day 7 Browser SPA

This lab deliberately stores OAuth tokens in browser sessionStorage so you can compare the SPA trust boundary with the server-side Web Application. Do not treat this storage choice as a universal production recommendation.

What to inspect

  1. Browser DevTools Network tab during sign-in.
  2. The callback request containing code and state.
  3. The browser-side POST to the Okta token endpoint.
  4. Application > Session Storage for this localhost origin.

This page never prints the raw token strings. Inspect their existence and storage location, not the credentials themselves.
